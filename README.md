# 음성 투두 (Android)

음성으로 할 일을 등록하면 **3시간 / 6시간 / 9시간 / 하루**마다 알림을 보내 주는 안드로이드 앱입니다.
데이터는 서버 없이 **스마트폰 내부 SQLite DB**에만 저장됩니다.

## 기능
- 🎤 마이크 버튼 → 말하면 바로 할 일 추가 (한국어 음성 인식)
- 말 속에 간격을 넣으면 자동 인식
  - "3시간마다 물 마시기" → 3시간마다
  - "보고서 쓰기 여섯 시간마다 알려줘" → 6시간마다
  - "매일 영양제 먹기" / "하루에 한 번 운동하기" → 하루마다
  - 간격을 말하지 않으면 화면 위에서 선택한 간격(기본 6시간) 사용
- 키보드로 직접 입력도 가능
- 할 일을 누르면 알림 간격 변경, 체크하면 완료(알림 중지), 휴지통으로 삭제
- 🔊 **음성 알림(TTS)**: 알림이 올 때 "할 일 알림. 물 마시기"처럼 소리내어 읽어줌
  - 화면 위 스위치로 켜고 끄기 (기본 켜짐), 무음·진동·방해금지 모드에선 읽지 않음
  - 할 일을 **길게 누르면** 미리 들어보기
  - 소리가 안 나면: 설정 → 일반 → 텍스트 음성 변환(TTS)에서 한국어 음성 데이터 설치
- 알림의 **[완료]** 버튼으로 앱을 열지 않고 바로 완료 처리
- 휴대폰 재부팅 후에도 알림 자동 복구 (꺼져 있던 동안 놓친 알림은 부팅 1분 뒤 알림)

## 설치 방법 (둘 중 하나)

### A. Android Studio (가장 간단)
1. 이 폴더를 Android Studio에서 **Open**
2. Gradle 동기화가 끝나면 폰을 USB로 연결(개발자 옵션 → USB 디버깅 켜기)
3. ▶ Run 버튼 → 폰에 바로 설치
   - APK 파일만 필요하면: Build → Build APK(s) → `app/build/outputs/apk/`

### B. GitHub에서 자동 빌드 (PC에 Android Studio 없이)
1. 이 폴더를 GitHub 저장소(비공개 가능)에 올림
2. 저장소의 **Actions** 탭 → "Build APK" 작업이 자동 실행 (약 3~5분)
3. 완료된 작업 화면 하단 **Artifacts → VoiceTodo-apk** 다운로드 → 압축 풀기
4. APK를 폰으로 옮겨 실행 → "출처를 알 수 없는 앱 설치" 허용 후 설치

## 처음 실행 시
- **알림 허용**을 꼭 눌러 주세요 (Android 13 이상).
- 삼성 갤럭시 등에서 알림이 늦게 오거나 안 오면:
  설정 → 애플리케이션 → 음성 투두 → 배터리 → **제한 없음** 으로 바꿔 주세요.
- 음성 인식은 폰의 Google 음성 인식을 사용합니다. 안 되면 Google 앱을 업데이트하세요.

## 구조
| 파일 | 역할 |
|---|---|
| `MainActivity.java` | 화면, 음성 입력, 추가/완료/삭제/간격 변경 |
| `TodoDb.java` | 로컬 SQLite DB (`voice_todo.db`) |
| `VoiceParser.java` | 음성 문장에서 "3시간마다", "매일" 등 간격 추출 |
| `Speaker.java` | 할 일 소리내어 읽기(TTS) · 음성 알림 설정 |
| `Reminders.java` | 알람 예약(AlarmManager) · 알림 표시 |
| `ReminderReceiver.java` | 알람 수신 → 알림 띄우고 다음 알람 예약, [완료] 버튼 처리 |
| `BootReceiver.java` | 재부팅/업데이트 후 알람 복구 |

외부 라이브러리 없이 안드로이드 기본 API만 사용 (minSdk 26 = Android 8.0 이상).

## 참고
- 정확한 시각 알림을 위해 `USE_EXACT_ALARM` 권한을 씁니다. 개인 설치(APK)에는 문제없지만,
  Play 스토어에 올리려면 정책 심사 대상이라 `setWindow` 방식 등으로 바꾸는 것을 검토하세요.
- 릴리스 APK는 편의상 디버그 키로 서명되어 있습니다(개인용). 배포용이면 별도 서명 키를 만드세요.
